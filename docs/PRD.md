## 1. 文档目的

本文档定义「台州直饮水运维系统」微信小程序的产品目标、功能范围、版本规划、业务规则及验收标准，作为产品设计、研发、测试及项目管理的依据。

## 2. 产品背景

### 2.1 业务背景

台州直饮水项目覆盖多个住宅小区，运维人员需日常负责：

- 监控净水/直饮/软水等设备的运行状态
- 处理用户用水相关问题，必要时远程操作阀门
- 按计划执行设备巡检并记录结果
- 查看维保计划，掌握设备保养安排

现有 HTML 原型已验证核心交互路径，需在此基础上明确 V1 产品边界，并面向微信小程序正式落地。

### 2.2 产品定位

面向**直饮水运维人员**的移动端工作台，提供设备监控、用户服务、巡检执行、维保计划查看等能力，帮助运维人员高效完成日常运维任务。

### 2.3 产品目标

| 目标 | 说明 |
|------|------|
| 提升运维效率 | 按小区→泵房→设备层级快速定位问题设备 |
| 规范作业流程 | 巡检执行标准化，结果可回溯 |
| 保障用户服务 | 用户用水信息可查，阀门操作有审批保障 |
| 支撑管理决策 | 维保计划、设备状态、耗材情况可汇总查看 |

## 3. 用户与场景

### 3.1 目标用户

| 用户角色 | 说明 | V1 支持 |
|----------|------|---------|
| 运维人员 | 负责管辖小区内设备巡检、故障处理、用户服务等 | ✅ 唯一角色 |
| 其他角色 | 管理员、客服、只读查看等 | ❌ 暂不实现，架构预留扩展 |

**典型用户画像**：张运维，高级运维工程师，管辖 3 个小区，服务约 2,450 户用户。

### 3.2 核心使用场景

| 编号 | 场景 | 涉及模块 |
|------|------|----------|
| S01 | 上班打开小程序，查看今日待办巡检和设备运行概况 | 首页、巡检管理 |
| S02 | 收到设备异常通知，按小区找到对应泵房和设备，查看运行数据 | 设备管理 |
| S03 | 用户反映无法用水，查询用户信息并申请关阀，等待主管审批 | 用户服务 |
| S04 | 到达小区现场，按巡检计划填写产水/供水模式检查表并提交 | 巡检管理 |
| S05 | 查看本周维保计划，提前准备备件和工具 | 维保管理 |
| S06 | 查看各小区耗材到期情况，安排更换计划 | 耗材管理（展示） |

## 5. 功能需求摘要

### 5.1 首页

- 展示运维统计、待办任务、设备运行概览、常用功能入口、最近报警
- V1 统计数据可 Mock，接口预留
- 常用功能入口包含 V1 四个核心模块

### 5.2 设备管理

- **一级**：按小区汇总设备数量及四态统计（在线/离线/预警/故障）
- **二级**：按泵房分组展示小区内设备，支持状态、种类筛选及搜索
- **三级**：设备详情含综合信息、历史报警、历史操作、报警参数设置
- 小区汇总页状态栏仅展示，不支持点击筛选

### 5.3 用户服务

- 用户列表支持标签（全部/欠费/关阀/长期未用水）、小区、关键词筛选
- 用户详情含用水详情、阀门操作、操作记录
- **阀门开/关操作必须经过二次审批**，审批通过后方可执行

### 5.4 巡检管理

- 计划列表按类型（设备巡检/水质检测）、状态（全部/待执行/已完成）筛选
- 支持新建巡检计划
- 设备巡检执行含产水模式、供水模式完整表单
- 提交后计划标记已完成，可查看汇总
- 水质检测执行表单 V1 不实现

### 5.5 维保管理

- 维保计划、维保记录两个 Tab，支持小区、设备类型、状态筛选
- 卡片可展开查看详情
- V1 只读，无新建、执行、完成操作

### 5.6 耗材管理（V1 展示）

- 按小区汇总耗材状态（正常/即将到期/已超期）
- 小区明细按设备分组展示耗材更换信息
- V1 不支持登记更换

### 5.7 报警管理（V1 展示）

- 列表展示、状态筛选、未处理报警可处理
- V1 不做关联设备跳转、处理中续办

### 5.8 我的（V2）

- V1 不实现

## 6. 业务规则

### 6.1 设备状态

| 状态 | 含义 |
|------|------|
| 在线 | 设备正常运行，数据上报正常 |
| 离线 | 设备通信中断，无法获取数据 |
| 预警 | 存在需关注项（如滤芯寿命偏高、压力偏低） |
| 故障 | 设备停机或关键部件异常 |

### 6.2 用户标签规则

| 标签 | 规则 |
|------|------|
| 欠费 | 账户余额 < 50 元 |
| 关阀 | 阀门状态为「关闭」 |
| 长期未用水 | 近 7 天用水量均为 0 |

### 6.3 阀门二次审批

```
运维人员发起申请 → 待审批 → 审批人处理 → 已通过/已驳回
                                    ↓（通过）
                              执行阀门指令 → 已执行/执行失败
```

- 开阀、关阀均需审批
- 所有操作记录写入用户操作历史
- 审批人机制待 V1 详细设计时确认（固定主管 / 按小区分配）

### 6.4 耗材状态计算

以系统当前日期为基准，根据「下次更换日期」计算：

| 条件 | 状态 |
|------|------|
| 剩余天数 < 0 | 已超期 |
| 剩余天数 ≤ 30 | 即将到期 |
| 剩余天数 > 30 | 正常 |

### 6.5 巡检状态流转

```
待执行 →（点击开始巡检）→ 进行中 →（提交表单）→ 已完成
```

- 退出执行页不保存草稿
- 水质检测类计划 V1 不可执行

## 7. 数据与接口

### 7.1 设计原则

- V1 前端可继续使用 Mock 数据开发
- 所有读写操作按 RESTful API 设计，便于后续对接后台
- 关键实体：小区、泵房、设备、用户、报警、巡检计划、维保计划、耗材

### 7.2 核心接口清单（预留）

| 模块 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 设备 | GET | /api/devices/summary | 小区设备汇总 |
| 设备 | GET | /api/devices | 小区设备列表 |
| 设备 | GET | /api/devices/:id | 设备详情 |
| 设备 | PUT | /api/devices/:id/alarm-config | 报警参数设置 |
| 用户 | GET | /api/users | 用户列表 |
| 用户 | GET | /api/users/:id | 用户详情 |
| 用户 | POST | /api/valve/apply | 发起阀门操作申请 |
| 用户 | GET | /api/valve/apply/:id/status | 查询审批状态 |
| 巡检 | GET | /api/inspect/plans | 巡检计划列表 |
| 巡检 | POST | /api/inspect/plans | 新建计划 |
| 巡检 | PUT | /api/inspect/plans/:id/start | 开始巡检 |
| 巡检 | PUT | /api/inspect/plans/:id/submit | 提交结果 |
| 维保 | GET | /api/maint/plans | 维保计划（只读） |
| 维保 | GET | /api/maint/records | 维保记录（只读） |
| 耗材 | GET | /api/consumables/summary | 小区耗材汇总 |
| 耗材 | GET | /api/consumables | 小区耗材明细 |

### 7.3 实体关系

```
小区 ──包含──> 泵房 ──包含──> 设备
设备 ──产生──> 报警记录 / 耗材记录
设备 ──关联──> 巡检计划 / 维保计划
小区 ──包含──> 用户 ──产生──> 用水记录 / 阀门操作记录
```

## 8. 非功能需求

| 类别 | 要求 |
|------|------|
| 平台 | 微信小程序，兼容 iOS / Android 微信客户端 |
| 基础库 | 微信基础库 ≥ 2.10.0 |
| 性能 | 列表首屏 < 2s；筛选响应 < 300ms |
| 网络 | 弱网下有 loading 提示；关键操作支持失败重试 |
| 安全 | 阀门操作必须二次审批；敏感操作留审计日志 |
| 视觉 | 主色 #3B82F6；状态色：绿（正常）、灰（离线）、橙（预警）、红（故障/超期） |
| 扩展性 | 用户模型预留 role 字段，支持未来多角色 |

## 9. 验收标准

### 9.1 设备管理

- [ ] 首页/底部导航可进入设备管理
- [ ] 展示全部小区设备及四态汇总
- [ ] 可按小区名称搜索
- [ ] 点击小区进入泵房分组设备列表
- [ ] 可按状态、种类筛选，可按名称/泵房/位置搜索
- [ ] 点击设备进入详情，4 个 Tab 数据完整展示
- [ ] 报警参数可提交（接口 Mock 可接受）

### 9.2 用户服务

- [ ] 可按标签、小区、关键词筛选用户
- [ ] 用户详情展示用水信息及分月明细
- [ ] 发起阀门操作后状态为「待审批」
- [ ] 审批通过后阀门状态更新，操作记录可查
- [ ] 审批驳回后展示驳回原因

### 9.3 巡检管理

- [ ] 可按类型、状态筛选巡检计划
- [ ] 可新建巡检计划
- [ ] 待执行计划可开始巡检并填写产水/供水表单
- [ ] 提交后计划变为已完成
- [ ] 已完成计划可查看汇总
- [ ] 水质检测执行入口显示「开发中」

### 9.4 维保管理

- [ ] 可切换维保计划/维保记录 Tab
- [ ] 可按小区、设备类型、状态筛选
- [ ] 卡片可展开查看详情
- [ ] 无新建、执行、完成操作入口

### 9.5 耗材管理（展示）

- [ ] 可按小区查看耗材汇总
- [ ] 可进入小区查看按设备分组的耗材明细
- [ ] 展示上次更换、下次更换、剩余天数、状态
- [ ] 无登记更换操作入口
