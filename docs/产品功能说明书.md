#### 3.4.7 报警参数设置

**适用设备类型**：供水泵、净水机、消毒设备

**参数项**：

| 参数 | 单位 | 默认范围 | 说明 |
|------|------|----------|------|
| TDS 值 | ppm | 0～100 | 超限触发报警 |
| 余氯 | mg/L | 0.05～0.50 | 超限触发报警 |
| pH 值 | — | 6.5～8.5 | 超限触发报警 |
| 压力 | MPa | 0.10～0.40 | 超限触发报警 |
| 流量 | L/h | 5～200 | 超限触发报警 |

每项可独立启用/禁用，设置最小值、最大值。点击「保存设置」提交（V1 可 Mock）。

#### 4.3.3 阀门操作（二次审批）

**操作流程**

```
1. 运维人员选择「开阀」或「关阀」
2. 弹出确认框，填写操作原因（必填）
3. 提交申请，状态变为「待审批」
4. 审批人审批（通过/驳回）
5. 通过 → 后台执行阀门指令 → 状态更新为「已执行」
6. 驳回 → 展示驳回原因
7. 操作记录写入「操作记录」Tab
```

**申请单字段**

| 字段 | 说明 |
|------|------|
| userId | 用户 ID |
| action | 开阀 / 关阀 |
| reason | 操作原因 |
| applicant | 申请人（当前运维人员） |
| applyTime | 申请时间 |
| status | 待审批 / 已通过 / 已驳回 / 已执行 / 执行失败 |
| approver | 审批人 |
| approveTime | 审批时间 |
| rejectReason | 驳回原因（驳回时） |

**页面状态展示**

| 状态 | 页面展示 |
|------|----------|
| 无进行中申请 | 显示开阀/关阀按钮 |
| 待审批 | 显示「审批中」提示，按钮禁用 |
| 已通过待执行 | 显示「执行中」 |
| 已执行 | 刷新阀门状态，显示成功提示 |
| 已驳回 | 显示驳回原因，可重新申请 |

#### 4.3.4 操作记录

| 字段 | 说明 |
|------|------|
| time | 操作时间 |
| user | 操作人员 |
| action | 开阀 / 关阀 |
| reason | 操作原因 |
| status | 审批及执行结果 |

### 5.3 页面二：巡检执行

#### 5.3.1 产水模式

**运行参数**

| 字段 | 单位 |
|------|------|
| 原水泵出口压力 | MPa |
| 产水电导率 | PPM |
| 膜前进口压力 | MPa |
| 膜后出口压力 | MPa |
| 产水流量 | M³-L/H |
| 浓水快排压力 | MPa |

**环节状态**（每项：正常/异常）

浓水排放、多介质过滤、活性炭过滤、软化过滤、市政压力/水箱液位、浓水快速排放、预处理紫外灯、产水合格阀、产水不合格阀、预处理排放阀

**耗材更换记录**

| 耗材 | 字段 |
|------|------|
| 保安过滤 PP 棉 | 是否更换 + 更换日期 |
| 回水 PP 棉 | 是否更换 + 更换日期 |

#### 5.3.2 供水模式

**运行参数**：高区/低区水泵编号、出水压力、电流、变频器频率、净水箱液位、回水电导率、加盐频率、消毒模式

**巡检状态**：接线、空气开关、电子元器件、指示灯、防水、防尘、变频器运行、PLC 运转、远程通讯状态、水泵运行、电机运行、机械密封、臭氧机测试、水箱排污、刷卡开门、水位报警、摄像头方向、泵房环境等 30+ 项

**水质数据**：浊度、臭氧、pH、温度、电导率

**管道巡检说明**：高区管道说明、低区管道说明

**抄表记录**：电表、原水表、产水表、水质水表度数及日期

**其他设施说明**：自由文本

#### 5.3.3 提交规则
